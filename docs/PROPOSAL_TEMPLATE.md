# Proposal template

Generated by `src/proposal/generator.py`. Outputs MD + HTML, plus PDF if WeasyPrint is available (it is in the Docker image).

## Inputs (all optional except `client_name`)

| Field | Notes |
|---|---|
| `client_name` | **required** |
| `industry` | Free text — used in the header |
| `package` | `Starter` / `Pro` / `Enterprise`, or a custom name |
| `add_ons` | String or comma-separated list |
| `timeline` | Default `"3–5 weeks"` |
| `price` | Number (INR by default; pass `currency` to override) |
| `support_plan` | Default `"Standard monthly support"` |
| `payment_terms` | List of bullet strings; defaults to the 5-point agency standard |
| `notes` | Free-text section appended near the bottom |

## Default payment terms (per agency policy)
- 50% advance to begin work
- 50% before launch / handover
- Support starts after launch
- Add-ons billed separately
- Prices exclude GST where applicable

## Output files
- `data/proposals/proposal_<slug>_<YYYY-MM-DD>.md`
- `data/proposals/proposal_<slug>_<YYYY-MM-DD>.html`
- `data/proposals/proposal_<slug>_<YYYY-MM-DD>.pdf` (when `make_pdf=True`)

## CLI shortcut
```bash
bash scripts/create_proposal.sh "Aurelia Architects" pro 34999 "WhatsApp lead capture,Google Sheet sync" architects
```
This builds the proposal **and** sends the MD + HTML (+ PDF) to Telegram automatically.

## Editing the template
The skeleton is in `src/proposal/generator.py::_md()`. Keep it short, opinionated, and avoid filler — the proposal is meant to feel premium and decisive.
